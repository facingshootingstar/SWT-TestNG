I Why

Three walls

🚫
No groups
Run only the smoke tests? No mechanism.
🔗
No dependencies
Login fails, checkout runs anyway — and fails too.
📋
No parameters
Ten datasets meant ten copy-pasted methods.

JUnit 3 was built for isolated unit tests. Integration tests are not isolated.

II Cons

What it costs

🧩
Complexity
Groups, dependencies, factories, listeners, XML. Powerful combined — and a real learning curve. Misused dependencies hide the real failure behind a chain of skips.
🪨
Overkill for unit tests
One monolithic dependency vs JUnit 5's modular Platform / Jupiter / Vintage. If you only write fast isolated unit tests, the orchestration engine is dead weight — and Spring Boot defaults to JUnit 5.
